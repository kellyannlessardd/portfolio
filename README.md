Porfolio - Kelly-Ann Lessard

Description du programe:
Ce projet est un siteweb porfolio personel réalisé dans le cadre du cours SED2515

Mon portfolio présente mon parcours académique, mes expérience professionnelles, mes compétences, mes projets, et mes info de contact.

Site développé avec REACT, TypeScript et Vite.

J'ai réalisé et développé la majorité du code de ce projet. Toute aide ou tout code provenant d'une autre source est indiqué dans les fichiers avec des commentaires.

Code Écriture Pourcentage:
Code Prof. Slii : 10%-15%
Code Kelly-Ann Lessard : 80%-85%
Code IA : 5%

Instruction pour exécuter les tests:
    Installer les dépendances avec: npm install
    Lancer le projet avec: npm run dev
    Tester: npm test
